# v1.1 Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settings gets a right-side city picker (geocoded matches fill city, zone, coordinates), a full zone list, a Save row with a discard prompt and a screensaver-timer row; Home's world clocks go digital with that city's weather; the top-bar Search opens All apps with type-to-filter; the greeting reads "Good Afternoon, Nickesh".

**Architecture:** Pure, tested helpers carry every decision (`SettingsDraft` merge/dirty over draft-owned fields, `ZoneCatalog`, `IdleOptions`, `AppFilter`, `ClockEdit`, `ClockMath.greeting`); the weather layer generalises from one city to a `Place` per key (`home`, `clock0..2`) with per-key cache and freshness by coordinates; `MainActivity` hoists the Settings draft above the screen switch; the Settings screen gains a right-hand panel slot used by the city picker, the zone list and the timer list; `WorldClockCard` drops the dial. All visuals derive from v1's glass components.

**Tech Stack:** Kotlin + Compose for TV, DataStore Preferences, kotlinx-serialization, OkHttp, Open-Meteo geocoding/forecast, JUnit 4; adb via `tools/tv.sh`.

**Spec:** `docs/superpowers/specs/2026-10-30-v1-1-fixes-design.md` (v1 context: `2026-10-29-tv-launcher-v1-design.md`).
